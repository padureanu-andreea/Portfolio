## Featured Projects

### SmartHire — AI-Assisted Recruitment Management Platform

**Type:** Individual Project · Bachelor's Thesis

**Technologies:** React · Node.js · Express · PostgreSQL · Python · FastAPI · REST APIs · JWT · Machine Learning · NLP · OpenAI API · Docker · Swagger

SmartHire is a full-stack recruitment management platform designed to support the complete recruitment workflow, from job creation and candidate applications to automated CV analysis, candidate ranking, interviews and recruitment analytics.

**Key features:**
- Role-based access for candidates, recruiters, managers and administrators
- Job creation, publication and application management
- PDF CV upload, parsing and candidate information extraction
- Semantic CV–job matching using multilingual sentence embeddings
- Machine-learning-based compatibility scoring
- AHP-based weighting of recruitment criteria
- AI-assisted bias detection and reformulation of job descriptions
- Automated candidate ranking
- Interview scheduling and feedback management
- Candidate notifications and virtual assistant
- Recruitment statistics and visual reports
- REST API documentation with Swagger
