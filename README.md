# Portfolio

This repository contains a collection of projects developed during my studies.

## Projects

### Anti-Food Waste Application
**Technologies:** React, Node.js, JavaScript, HTML, CSS, Relational Databases  
A web application that helps users reduce food waste by sharing surplus food with others.

---

### Demographic Clustering Analysis of Romanian Counties
**Technologies:** Python  
Applied hierarchical clustering (Ward method) to group Romanian counties based on demographic indicators and identify regional patterns in population dynamics.

---

### Pharmacy Database Management System
**Technologies:** SQL, PL/SQL  
Built a relational database system for pharmacy management, implementing schema design, SQL queries, procedures, functions and triggers for managing medications, suppliers, clients and sales.

---

### Real Estate Agency Management Application
**Technologies:** C#.NET, Relational Databases  
Desktop application for managing properties, agents, clients and real estate offers within a real estate agency.

---

### SVG Graphics Editor
**Technologies:** HTML, CSS, JavaScript  
Web-based SVG editor for drawing and editing vector shapes with features such as element manipulation and export functionality.

---

### Plant Management System Backend
**Technologies:** Python, APIs, Relational Databases, GitHub  
Developed the backend for a plant management system modeling manufacturing entities and processes, including API development, database design, testing and collaborative development using GitHub.
